# Currículo

`curriculo.html` é o fonte. O PDF publicado fica em `public/assets/Roberto_GabrielCV.pdf`,
que é o arquivo linkado pelo portfólio.

## Regerar o PDF

Abrir `curriculo.html` no navegador e imprimir (Ctrl/Cmd+P) → **Salvar como PDF**,
com margens em **Nenhuma** e "Gráficos de fundo" ligado. A folha já é A4 com as
margens embutidas no `.page`.

O conteúdo foi ajustado para caber em **exatamente uma página**. Ao adicionar
qualquer coisa, confira se não passou para a segunda — a altura útil de uma A4
a 96dpi é 1123px.
